# Plasma Days Since

A Plasma 6 applet to view number of days since significant dates.

## Installation

1. Clone the repository:

```
git clone https://github.com/shsiddhant/plasma-days-since
```

2. Install the widget:

```
kpackagetool6 -t Plasma/Applet -i plasma-days-since/package
```

For upgrades, use:

```
kpackagetool6 -t Plasma/Applet -u plasma-days-since/package
```

## Configuration

Right-click the applet and select the configure option to manage events.

Each event consists of a title and a date.
